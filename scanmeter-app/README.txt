scanmeter-app
Version 1.0

=========================================
概要
=========================================

scanmeter-app は検針票PDFをOCR解析し、
CSVファイルへ変換するアプリです。

インターネット接続は不要です。

処理はすべてPC内で実行されます。


=========================================
対応内容
=========================================

・PDFアップロード
・OCR解析
・進捗表示
・CSV生成
・CSVダウンロード
・処理完了後自動クリーンアップ


=========================================
動作環境
=========================================

Windows 10
Windows 11

推奨メモリ

8GB以上


=========================================
起動方法
=========================================

scanmeter-app.exe

をダブルクリックしてください。

数秒後にブラウザが起動します。

起動しない場合は

http://127.0.0.1:8000

へアクセスしてください。


=========================================
利用手順
=========================================

① PDFを選択

② OCR開始を押す

③ 進捗を待つ

④ CSV出力完了

⑤ CSVを保存する


=========================================
処理中の注意
=========================================

OCR実行中は

・アプリを終了しない
・ブラウザを閉じない
・PCをシャットダウンしない

でください。

ページ数が多いPDFは
完了まで時間がかかります。


=========================================
フォルダ説明
=========================================

scanmeter-app.exe
    アプリ本体

runtime
    OCR実行環境

temp
    一時ファイル保存先

logs
    ログ保存先


=========================================
エラー発生時
=========================================

以下を確認してください。

・PDFが破損していないか
・ディスク容量不足ではないか
・ウイルス対策ソフトに
  ブロックされていないか

改善しない場合は

logs

フォルダ内のログを確認してください。


起動できない場合

・ ZIPを右クリック
・ プロパティ
・ ブロック解除
 展開
5. scanmeter-app.exe を起動


=========================================
一時ファイルについて
=========================================

処理中に生成された

・PDF
・CSV
・進捗データ

は処理完了後に自動削除されます。


=========================================
アンインストール
=========================================

scanmeter-app フォルダを
削除するだけです。

レジストリは使用しません。
