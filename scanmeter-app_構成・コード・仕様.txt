scanmeter-app 構成・コード・仕様
================================

確認日: 2026-10-29

この資料は、application フォルダ内にある scanmeter-app と project-root の
ファイルを確認してまとめたものです。


1. アプリ概要
-------------

検針票 PDF をローカル PC 上で OCR 処理し、読み取った文字列を CSV にして
ダウンロードするローカル Web アプリです。

- Web サーバー: Python / FastAPI / Uvicorn
- PDF ページ画像化: Poppler（pdf2image 経由）
- 日本語 OCR: Tesseract（pytesseract 経由、jpn 言語データ）
- 動作ポート: 8000
- サーバーの待受先: 127.0.0.1（同じ PC 内からの利用）
- データ保存先: アプリ内の temp フォルダ

README には Windows 10 / Windows 11、推奨メモリ 8 GB 以上と記載されています。
この環境条件は README 上の記載であり、本資料作成時に各環境での動作試験は
実施していません。


2. フォルダ構成
---------------

配布用フォルダとして存在する scanmeter-app の主な構成:

scanmeter-app\
|-- launcher.py                 Python から起動するランチャー
|-- README.txt                  利用者向け説明
|-- app\
|   |-- main.py                 FastAPI アプリ、画面とルーターの登録
|   |-- config\
|   |   |-- settings.py         配布フォルダ、OCR 実行ファイル等のパス設定
|   |-- routers\
|   |   |-- upload_router.py    PDF アップロード、OCR開始、CSVダウンロード
|   |   |-- progress_router.py  進捗データの返却
|   |   |-- cleanup_router.py   一時 PDF / CSV の削除、進捗初期化
|   |-- services\
|   |   |-- ocr_service.py      PDF画像化、OCR、進捗更新、CSV生成
|   |-- templates\
|       |-- index.html          アップロード画面、進捗表示、ダウンロード処理
|-- runtime\
|   |-- poppler\                PDFページ画像化用プログラムと関連ファイル
|   |-- tesseract\              Tesseract本体、DLL、日本語等の学習データ
|-- temp\                       アップロードPDF、生成CSV、progress.json の保存先
|-- logs\                       ログ用フォルダ

app/static 内は空のディレクトリのみで、画面の JavaScript は index.html 内に
記述されています。

元ソースと思われる project-root には、上記に加えて Dockerfile、
requirements.txt、起動.bat、および以下の追加コードがあります。

- app/services/company_detector.py
- app/services/csv_generator.py
- app/services/ocr/pdf_ocr.py
- app/services/ocr/image_ocr.py
- app/services/ocr/html_parser.py
- app/services/ocr/company/tepco.py
- app/services/ocr/company/chuden.py
- app/services/ocr/company/hokuriku.py
- app/services/ocr/company/tohoku.py

これらの追加コードは scanmeter-app 配布フォルダには含まれていません。
また、確認した ocr_service.py からこれらの会社別抽出処理が呼び出されている
ことは確認できませんでした。したがって、現行の配布フォルダの処理仕様と、
元ソース側に置かれた追加コードは区別してください。


3. 主なコードの役割
-------------------

launcher.py
  temp と logs のフォルダを作成し、Uvicorn でアプリを起動します。
  起動から約2秒後に http://127.0.0.1:8000 をブラウザーで開きます。

app/main.py
  FastAPI アプリを作成し、トップ画面とヘルスチェックを提供します。
  アップロード、進捗、クリーンアップの各ルーターを登録します。

app/config/settings.py
  アプリの基準フォルダを起点に runtime、temp、Tesseract 実行ファイル、
  Poppler の実行ファイルフォルダのパスを組み立てます。

app/routers/upload_router.py
  POST /upload でアップロードされたファイルを temp に保存し、OCRを
  バックグラウンドスレッドで開始します。処理後の CSV は GET /download
  で返します。

app/routers/progress_router.py
  GET /progress で temp/progress.json の内容を返します。ファイルがない場合は
  idle 状態を返します。

app/routers/cleanup_router.py
  POST /cleanup で temp 内の PDF と CSV を削除し、進捗を idle に戻します。

app/services/ocr_service.py
  Poppler で PDF の各ページを画像化し、Tesseract の日本語 OCR を実行します。
  認識した文字の座標を使って行ごとに並べ、CSV と進捗情報を作成します。

app/templates/index.html
  PDF選択、OCR開始、1秒間隔の進捗確認、CSVダウンロード、完了表示を行います。


4. HTTP エンドポイント
----------------------

GET  /          トップページ（PDFアップロード画面）
GET  /health    {"status": "ok"} を返すヘルスチェック
POST /upload    PDFを受け取り、OCR処理を開始
GET  /progress  OCRの状態、ページ数、進捗率を返す
GET  /download  作成済みCSVを result.csv として返す
POST /cleanup   temp 内のPDF / CSV削除と進捗状態の初期化

進捗情報には status、current、total、percent が含まれます。処理エラー時は
status が error となり、message にエラー内容が設定されます。


5. 処理の流れと出力仕様
-----------------------

1) ブラウザーで PDF を選び、OCR開始を押します。
2) POST /upload がファイルを temp に保存し、別スレッドで OCR を開始します。
3) Poppler でページ数を取得し、各ページを順番に画像化します。
4) Tesseract の jpn モデルで文字と座標を取得します。
5) OCR文字をおおよそ15ピクセル単位の縦位置グループに分け、左から順に
   並べて行文字列にします。
6) OCR結果を temp 内の CSV に保存します。
7) ブラウザーは約1秒ごとに進捗を確認し、完了すると /download から
   result.csv を自動ダウンロードします。
8) 完了画面で OK を押すと /cleanup が呼ばれ、一時 PDF / CSV と進捗状態が
   削除・初期化されます。

CSV は UTF-8 BOM 付きです。列は「OCR結果」の1列で、認識した各行を
1レコードずつ格納します。電力会社名や請求額などの項目別CSVではなく、
現行 scanmeter-app の実装はOCRテキストの行単位出力です。


6. 配布・動作上の確認事項
-------------------------

- README.txt は scanmeter-app.exe の起動を案内していますが、確認した
  scanmeter-app フォルダ内に scanmeter-app.exe はありません。存在する
  launcher.py は Python と必要な Python パッケージがある環境で実行する
  スクリプトです。
- scanmeter-app には requirements.txt がありません。元ソース側
  project-root\requirements.txt には FastAPI、Uvicorn、pdf2image、
  Pillow、pytesseract 等が記載されています。
- project-root\起動.bat は Docker Desktop と scanmeter-app:latest イメージを
  前提とする起動スクリプトで、scanmeter-app 配布フォルダには含まれて
  いません。
- 画面は https://cdn.tailwindcss.com から Tailwind CSS を読み込みます。
  OCR処理とサーバーはローカルですが、画面のスタイル取得にはネット接続が
  必要になる場合があります。そのため README の「インターネット接続不要」
  という記載は、画面表示の見た目まで含めると条件付きです。
- 画面のファイル選択欄は .pdf を指定していますが、サーバー側でPDF形式や
  ファイルサイズを検証する処理は確認できません。
- PDFはOCR成功時に処理スレッド内で削除されます。CSV等の後片付けは
  完了画面で OK を押した後に行われます。READMEの「処理完了後自動削除」
  は操作上のこの条件を補足して理解してください。
- ポートは 8000 固定です。別のプロセスが使用中の場合は起動できないことが
  あります。


7. 利用上の注意
---------------

- OCR結果はPDFの画質、傾き、印字状態に左右されます。重要な数値は原本と
  照合してください。
- 多ページPDFでは処理に時間がかかります。処理中はサーバーを終了しないで
  ください。
- エラー時は logs の内容を確認してください。ただし、本資料作成時に
  ログ出力先へのアプリログ記録処理はコード上で確認できていません。
- 配布時には、READMEの起動方法、必要な Python 実行環境、Python依存関係、
  外部CSSへの接続要件が実際のパッケージ内容と一致していることを確認して
  ください。

import threading
import webbrowser
import uvicorn
from pathlib import Path


HOST = "127.0.0.1"
PORT = 8000


def open_browser():
    webbrowser.open(
        f"http://{HOST}:{PORT}"
    )


def ensure_runtime_folders():

    base_dir = Path(__file__).resolve().parent

    (base_dir / "temp").mkdir(
        exist_ok=True
    )

    (base_dir / "logs").mkdir(
        exist_ok=True
    )


if __name__ == "__main__":

    ensure_runtime_folders()

    threading.Timer(
        2,
        open_browser
    ).start()

    uvicorn.run(
        "app.main:app",
        host=HOST,
        port=PORT,
        reload=False,
        log_level="info"
    )

import os
import glob
import json

from fastapi import APIRouter

router = APIRouter()

from app.config.settings import TEMP_DIR

PROGRESS_FILE = TEMP_DIR / "progress.json"


@router.post("/cleanup")
async def cleanup():

    # CSV削除
    for file in glob.glob(
        os.path.join(
            TEMP_DIR,
            "*.csv"
        )
    ):

        try:
            os.remove(file)
        except Exception:
            pass

    # PDF削除
    for file in glob.glob(
        os.path.join(
            TEMP_DIR,
            "*.pdf"
        )
    ):

        try:
            os.remove(file)
        except Exception:
            pass

    # progress初期化
    try:

        with open(
            PROGRESS_FILE,
            "w",
            encoding="utf-8"
        ) as f:

            json.dump(
                {
                    "status": "idle",
                    "current": 0,
                    "total": 0,
                    "percent": 0
                },
                f,
                ensure_ascii=False
            )

    except Exception:
        pass

    return {
        "status": "ok"
    }

import json
import os

from fastapi import APIRouter

router = APIRouter()

from app.config.settings import TEMP_DIR

PROGRESS_FILE = TEMP_DIR / "progress.json"


@router.get("/progress")
async def get_progress():

    # progressファイルが無い場合
    if not os.path.exists(PROGRESS_FILE):

        return {
            "current": 0,
            "total": 0,
            "percent": 0,
            "status": "idle"
        }

    try:

        with open(
            PROGRESS_FILE,
            "r",
            encoding="utf-8"
        ) as f:

            progress = json.load(f)

        return progress

    except Exception:

        return {
            "current": 0,
            "total": 0,
            "percent": 0,
            "status": "error"
        }

import json
import os
import threading

from uuid import uuid4

from fastapi import APIRouter
from fastapi import UploadFile
from fastapi import File
from fastapi import HTTPException

from fastapi.responses import FileResponse

from app.services.ocr_service import pdf_to_csv

router = APIRouter()

from app.config.settings import TEMP_DIR

UPLOAD_DIR = TEMP_DIR
PROGRESS_FILE = TEMP_DIR / "progress.json"

os.makedirs(
    UPLOAD_DIR,
    exist_ok=True
)

CURRENT_CSV = None


def run_ocr(
    pdf_path,
    csv_path
):
    global CURRENT_CSV

    try:

        result_csv = pdf_to_csv(
            pdf_path,
            csv_path
        )

        if os.path.exists(
            pdf_path
        ):
            os.remove(
                pdf_path
            )

        CURRENT_CSV = result_csv

    except Exception as e:

        with open(
            PROGRESS_FILE,
            "w",
            encoding="utf-8"
        ) as f:

            json.dump(
                {
                    "status": "error",
                    "current": 0,
                    "total": 0,
                    "percent": 0,
                    "message": str(e)
                },
                f,
                ensure_ascii=False
            )


@router.post("/upload")
async def upload_file(
    file: UploadFile = File(...)
):

    global CURRENT_CSV

    CURRENT_CSV = None

    with open(
        PROGRESS_FILE,
        "w",
        encoding="utf-8"
    ) as f:

        json.dump(
            {
                "status": "starting",
                "current": 0,
                "total": 0,
                "percent": 0
            },
            f,
            ensure_ascii=False
        )

    pdf_path = UPLOAD_DIR / f"{uuid4()}_{file.filename}"

    with open(
        pdf_path,
        "wb"
    ) as f:

        f.write(
            await file.read()
        )

    csv_path = pdf_path.with_suffix(".csv")

    thread = threading.Thread(
    target=run_ocr,
    args=(
        str(pdf_path),
        str(csv_path)
    ),
    daemon=True
)

    thread.start()

    return {
        "status": "started"
    }


@router.get("/download")
def download_csv():

    global CURRENT_CSV

    if not CURRENT_CSV:
        raise HTTPException(
            status_code=404,
            detail="CSV未生成"
        )

    return FileResponse(
        CURRENT_CSV,
        filename="result.csv",
        media_type="text/csv"
    )

import os
import csv
import json

from pdf2image import (
    convert_from_path,
    pdfinfo_from_path
)

import pytesseract
from pytesseract import Output


# =========================
# Tesseract設定
# =========================

from app.config.settings import (
    TESSERACT_PATH,
    POPPLER_PATH,
    TEMP_DIR
)

pytesseract.pytesseract.tesseract_cmd = str(
    TESSERACT_PATH
)

PROGRESS_FILE = TEMP_DIR / "progress.json"


def update_progress(
    current,
    total,
    status="running"
):

    percent = 0

    if total > 0:
        percent = round(
            current / total * 100,
            1
        )

    with open(
        PROGRESS_FILE,
        "w",
        encoding="utf-8"
    ) as f:

        json.dump(
            {
                "status": status,
                "current": current,
                "total": total,
                "percent": percent
            },
            f,
            ensure_ascii=False
        )


def extract_text_horizontal(image):

    print("===== OCR START =====")
    print(
        "Tesseract Version:",
        pytesseract.get_tesseract_version()
    )

    data = pytesseract.image_to_data(
        image,
        lang="jpn",
        output_type=Output.DICT
    )

    rows = []

    count = len(
        data["text"]
    )

    for i in range(count):

        text = data["text"][i].strip()

        if not text:
            continue

        rows.append(
            {
                "text": text,
                "top": data["top"][i],
                "left": data["left"][i]
            }
        )

    rows.sort(
        key=lambda x: (
            round(x["top"] / 15),
            x["left"]
        )
    )

    return rows


def merge_rows(rows):

    merged_lines = []

    current_row = []
    current_top = None

    for row in rows:

        top_group = round(
            row["top"] / 15
        )

        if current_top is None:
            current_top = top_group

        if current_top != top_group:

            merged_lines.append(
                " ".join(current_row)
            )

            current_row = []
            current_top = top_group

        current_row.append(
            row["text"]
        )

    if current_row:

        merged_lines.append(
            " ".join(current_row)
        )

    return merged_lines


def pdf_to_csv(
    pdf_path,
    csv_path
):

    print("===== PDF INFO =====")

    info = pdfinfo_from_path(
    pdf_path,
    poppler_path=str(POPPLER_PATH)
)

    total_pages = info["Pages"]

    print(
        f"Total Pages: {total_pages}"
    )

    update_progress(
        0,
        total_pages
    )

    result_lines = []

    for page_no in range(
        1,
        total_pages + 1
    ):

        print(
            f"Page {page_no}"
        )

        update_progress(
            page_no,
            total_pages
        )

        print("convert start")

        images = convert_from_path(
            pdf_path,
            first_page=page_no,
            last_page=page_no,
            poppler_path=str(POPPLER_PATH)
        )
        print("convert done")

        image = images[0]

        rows = extract_text_horizontal(
            image
        )

        print("ocr done")

        lines = merge_rows(
            rows
        )

        result_lines.extend(
            lines
        )

    with open(
        csv_path,
        "w",
        newline="",
        encoding="utf-8-sig"
    ) as f:

        writer = csv.writer(f)

        writer.writerow(
            ["OCR結果"]
        )

        for line in result_lines:

            writer.writerow(
                [line]
            )

    update_progress(
        total_pages,
        total_pages,
        "completed"
    )

    return csv_path

function startProgressMonitor() {

    if (progressTimer) {

        clearInterval(
            progressTimer
        );
    }

    fetchErrorCount = 0;

    progressTimer =
        setInterval(
            async () => {

                try {

                    const response =
                        await fetch(
                            "/progress"
                        );

                    const data =
                        await response.json();

                    fetchErrorCount = 0;

                    errorBox.classList.add(
                        "hidden"
                    );

                    lastCurrent =
                        data.current ?? lastCurrent;

                    lastTotal =
                        data.total ?? lastTotal;

                    lastPercent =
                        data.percent ?? lastPercent;

                    progressText.innerText =
                        `${lastCurrent} / ${lastTotal}`;

                    percentText.innerText =
                        `${lastPercent}%`;

                    progressBar.style.width =
                        `${lastPercent}%`;

                    if (
                        data.status === "completed"
                    ) {

                        clearInterval(
                            progressTimer
                        );

                        loadingBox.classList.add(
                            "hidden"
                        );

                        // CSV自動ダウンロード

                        const a =
                            document.createElement(
                                "a"
                            );

                        a.href =
                            "/download";

                        document.body.appendChild(
                            a
                        );

                        a.click();

                        a.remove();

                        // 完了モーダル

                        completeModal.classList.remove(
                            "hidden"
                        );

                        return;
                    }

                    if (
                        data.status ===
                        "error"
                    ) {

                        clearInterval(
                            progressTimer
                        );

                        loadingBox.classList.add(
                            "hidden"
                        );

                        errorBox.innerText =
                            data.message ||
                            "OCRエラー";

                        errorBox.classList.remove(
                            "hidden"
                        );

                        return;
                    }

                }
                catch(error) {

                    fetchErrorCount++;

                    console.warn(
                        "progress fetch error",
                        fetchErrorCount
                    );

                    // 最後の進捗を保持
                    progressText.innerText =
                        `${lastCurrent} / ${lastTotal}`;

                    percentText.innerText =
                        `${lastPercent}%`;

                    progressBar.style.width =
                        `${lastPercent}%`;

                    if (
                        fetchErrorCount >= 30
                    ) {

                        errorBox.innerText =
                            "進捗取得に失敗しています";

                        errorBox.classList.remove(
                            "hidden"
                        );
                    }
                }

            },
            1000
        );
}

def detect_company(text: str) -> str:
    """
    OCR/HTMLから抽出したテキストをもとに
    電力会社を判定する
    """

    # 東北電力
    if ("東北電力" in text) or ("ご使用量" in text and "東北" in text):
        return "東北電力"

    # 北陸電力
    if ("北陸電力" in text) or ("ほくリンク" in text):
        return "北陸電力"

    # 東京電力
    if ("東京電力" in text) or ("TEPCO" in text) or ("くらしTEPCO" in text):
        return "東京電力"

    # 中部電力
    if ("中部電力" in text) or ("カテエネ" in text):
        return "中部電力"

    # 判定できない場合
    return None

import csv

def generate_csv(data: dict) -> str:
    """
    抽出結果 dict を CSV に変換し、一時ファイルとして保存する
    FileResponse で返却できるようにファイルパスを返す
    """

    # 一時ファイルパス
    temp_id = str(uuid.uuid4())
    csv_path = f"/tmp/{temp_id}.csv"

    # CSVの列順（固定）
    headers = [
        "電力会社名",
        "契約種別",
        "検針日",
        "使用量(kWh)",
        "請求金額",
        "供給地点番号",
        "前月使用量",
        "燃料調整費",
        "再エネ賦課金",
        "基本料金",
        "従量料金",
        "電力量料金",
        "契約容量",
        "需要家番号",
        "請求月",
        "支払期限"
    ]

    # dict → CSV行に変換
    row = [
        data.get("company"),
        data.get("contract"),
        data.get("meter_date"),
        data.get("usage"),
        data.get("price"),
        data.get("supply_point"),
        data.get("prev_usage"),
        data.get("fuel_cost"),
        data.get("renewable_cost"),
        data.get("basic_fee"),
        data.get("meter_fee"),
        data.get("power_fee"),
        data.get("contract_amp"),
        data.get("customer_id"),
        data.get("billing_month"),
        data.get("due_date"),
    ]

    # CSV書き込み
    with open(csv_path, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(headers)
        writer.writerow(row)

    return csv_path

from bs4 import BeautifulSoup

def extract_text_from_html(html_path: str) -> str:
    """
    HTML（WEB版検針票）を DOM解析してテキスト抽出する
    """
    with open(html_path, "r", encoding="utf-8", errors="ignore") as f:
        html = f.read()

    soup = BeautifulSoup(html, "lxml")

    # HTML内のテキストをすべて抽出
    text = soup.get_text(separator="\n")

    return text

import os

def extract_text_from_pdf(pdf_path: str) -> str:
    """
    紙PDF（画像ベース）を OCR してテキスト抽出する
    """
    text = ""

    # PDF → 画像化（300dpi）
    images = convert_from_path(
        pdf_path,
        poppler_path=str(POPPLER_PATH)
)

    for img in images:
        # 一時ファイルに画像保存
        with tempfile.NamedTemporaryFile(delete=False, suffix=".png") as tmp:
            img.save(tmp.name, "PNG")
            tmp_path = tmp.name

        # OCR実行（日本語）
        page_text = pytesseract.image_to_string(tmp_path, lang="jpn")
        text += page_text + "\n"

        # 一時ファイル削除
        os.remove(tmp_path)

    return text
